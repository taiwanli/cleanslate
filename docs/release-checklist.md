## 回滚预案

### 应用回滚

1. **停更**：下架/暂停新安装包与自动更新。  
2. **切换分发**：将下载页指向 N-1 稳定版。  
3. **用户降级**：卸载当前版 → 安装 N-1；安装程序不得删除隔离区与历史 DB。  
4. **数据**：`settings.json` 向前兼容；若 schema 不兼容，保留 `backup/pre-upgrade/`。

### 数据/误删事故

| 级别 | 动作 |
|------|------|
| P0 大规模误删 | 公告 + 停更 + 恢复指引（隔离区/文件历史/卷影）+ hotfix |
| P1 清理崩溃等 | 48h 内 hotfix |
| P2 一般缺陷 | 计划修复 |

### 回滚触发条件

- 误删用户文档/模型/凭证的实锤报告  
- 安装包签名或恶意软件误报导致渠道下架  
- 启动即崩溃率超过约定阈值  

### 演练

- 每个大版本发布前做一次「降级到 N-1」桌面推演，记录耗时与数据检查结果。

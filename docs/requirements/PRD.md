| 字段 | 值 |
|------|-----|
| 状态 | 草稿 → 待 PO 签字 |

## 1. 背景与目标

Windows 自带卸载常留下缓存、注册表、服务与目录残留；Agent 类工具还会留下会话、缓存、模型与配置。CleanSlate 提供可审可控的卸载与残留治理，降低误删风险。

**产品主张**：扫得到 → 卸得干净 → 残留可清 → 历史可扫 → Agent 专项 → 误删可控。

## 2. 用户与场景

| 用户 | 典型场景 |
|------|----------|
| 普通用户 | 卸载软件并清掉残留；不希望误删文档 |
| 进阶用户/IT | 批量卸载、孤儿清理、隐藏项 |
| 开发者 | 清理 Claude Code / Cursor / 通义灵码等 Agent 缓存与会话 |

## 3. 范围内（MVP P0）

- 多源软件枚举（注册表/MSI/Store/隐藏/便携关联）
- 卸载 + 卸载后残留审阅清理
- 历史孤儿残留扫描
- Agent 规则包 v1（国内外高优先级）
- 风险分级、白名单、隔离区、撤销日志
- 液态玻璃 × 新拟态 UI（见 UI 报告）

## 4. 范围外（MVP）

- 实时安装监控驱动、软件搬迁、企业控制台、Win7

## 5. 验收标准（P0）

| ID | 需求 | 验收标准 | 优先级 |
|----|------|----------|--------|
| R1 | 列出已安装软件 | 含桌面/Store/隐藏；可搜索过滤 | P0 |
| R2 | 卸载后清残留 | 审阅列表可勾选；低风险默认可清；报告可导出 | P0 |
| R3 | 历史残留 | 识别孤儿并分组；高风险默认不选 | P0 |
| R4 | Agent 清理 | 分层 L1–L5；凭证/模型需二次确认 | P0 |
| R5 | 安全 | 保护路径不可删；隔离区可恢复；有撤销 | P0 |
| R6 | UI | 浅/深色可用；风险信息可见 | P1 |

## 6. 非功能

- Win10/11 x64；1000 条列表可滚动；删除全程有日志；默认不上传隐私数据。

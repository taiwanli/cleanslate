# 简卸（CleanSlate）交互与产品升级报告

> **版本**：v1.0（评审稿）  
> **目标**：解决「交互繁琐 / 接口重复 / 不敢清理 / 对小白不友好」，对齐市面卸载工具的高效交互，再进入开发  
> **参考**：Geek Uninstaller、Revo Uninstaller、IObit Uninstaller、BCUninstaller、HiBit 等同类产品公开功能与常见交互模式（结合本项目已有竞品调研）

---

## 1. 问题诊断（当前版）

| 问题 | 现象 | 影响 |
|------|------|------|
| **信息过载** | 侧栏 7 个入口；主界面同时出现扫描/历史/刷新/批量/语言/演示等按钮 | 小白不知道从哪点起 |
| **接口重复** | 「扫描残留」「历史残留」「强制卸载」「安全中心清理」语义重叠 | 学习成本高、误操作风险 |
| **设置外泄** | 中英切换、深色、演示数据直接放标题栏 | 主路径被挤占，专业功能与日常功能混杂 |
| **信任不足** | 清理按钮过于「工具感」，缺少「安全结果预览」 | 用户不敢点「清理」 |
| **流程断裂** | 列表 → 卸载 → 扫残留 → 审阅 → 清理，弹窗跳转多 | 任务不连贯 |
| **列表可读性** | Publisher 等英文长字段占满；风险只显示 Low 等英文 | 信息密度大、扫一眼抓不住重点 |
| **图标/品牌** | 已有简卸图标，但列表视觉仍偏「数据表」 | 缺少产品感与安全感 |

## 2. 同类产品交互借鉴（提炼为原则）

### 2.1 共性（市面主流）

| 能力 | Geek / Revo / IObit / BCU | 对简卸的启示 |
|------|---------------------------|--------------|
| **列表即工作台** | 一屏软件清单 + 搜索 + 排序；右键/详情做进阶 | 主界面只留「找软件 → 点卸载」 |
| **卸载后自动扫残留** | 卸载完直接进「残留清单」 | 合并为一条流水线 |
| **安全预览** | 残留按类型分组、可勾选、显示路径 | 明确「将删什么 / 能否恢复」 |
| **一键优化 / 智能推荐** | IObit「Software Health」；Revo 可信度 | 小白模式：推荐清理项 |
| **强制卸载** | 拖图标/文件夹即查痕迹 | 收进「更多工具」，不与主按钮并列 |
| **设置收纳** | 语言、主题、扫描深度、备份策略在设置 | 主界面零设置项 |
| **进度与结果** | 释放空间、成功/失败摘要 | 清理完有「成绩单」 |
| **便携/轻量** | Geek 单文件快启动 | 首屏加载要快，扫描可后台 |

### 2.2 差异化（简卸可保留并强化）

- **Agent 专项**（市面少有）— 做成「开发者清理」独立向导  
- **隔离区一键恢复** — 小白敢点的关键  
- **先审后删** — 强化为「安全承诺」文案，而不是多一层确认弹窗

## 3. 升级总原则

1. **一条主路径**：打开 → 选软件 → 卸载 → 自动扫残留 → 确认清理 → 完成  
2. **界面三层**：主区（日常）· 抽屉（进阶工具）· 设置（偏好）  
3. **信任设计**：每个删除项显示「安全/推荐/谨慎」+ 恢复方式；默认只勾推荐项  
4. **小白默认，专家可开**：扫描深度、隐藏项、强制卸载不进首屏  
5. **文案中文化 + 图标语义**：风险用颜色+图标+汉字，不只 Low/High  
6. **减少弹窗**：能用页内步骤条就不用连续 MessageBox

## 4. 信息架构（IA）重组

### 4.1 新侧栏（3 个主入口 + 1 设置）

```
简卸
├─ 软件清理          ← 默认首页（列表 + 一键体检）
├─ 深度清理          ← 残留 / 孤儿 / Agent（向导内切换）
├─ 工具箱            ← 强制卸载、软件搬迁、安装监控、扩展管理
└─ 设置
```

| 现有 | 迁移至 |
|------|--------|
| 软件列表 | 软件清理（首页） |
| 残留审阅 | 软件清理流程内「步骤 2」 |
| 历史残留 | 深度清理 · 孤儿残留 |
| Agent 专项 | 深度清理 · Agent |
| 安装监控 / 浏览器扩展 / 软件搬迁 | 工具箱 |
| 安全中心 | 设置 · 安全与恢复（+ 完成页入口） |
| 语言切换 | **设置** |
| 深色主题 | **设置**（或跟随系统） |
| 演示数据 | **删除**（仅 Debug 构建） |

### 4.2 设置页结构

```
设置
├─ 外观：主题（浅色/深色/跟随系统）、语言（中文/English）
├─ 清理：默认隔离区、保留天数、扫描深度（快速/标准/深度）
├─ 安全：保护路径、高风险需二次确认、创建还原点
├─ 隐私与关于：隐私说明、免责声明、版本、检查更新（CDN）
└─ 高级（折叠）：显示隐藏软件、开发者模式
```

## 5. 核心流程重设计

### 5.1 流程 A：软件清理（主路径，小白友好）

```
[1 软件列表] → 勾选/点卸载
      ↓
[卸载] 卸载器执行（可选关闭进程，默认不勾）
      ↓
[2 自动扫描残留] 进度动画 + 已发现 N 项
      ↓
[3 审阅清理] 默认仅「推荐」勾选
      ↓  确认
[4 完成] 释放 XX MB · [查看报告] [撤销/恢复]
```

**关键交互**

| 项 | 设计 |
|----|------|
| 首屏主按钮 | 右上仅 **「立即体检」**（扫描残留/孤儿/推荐清理）+ 搜索框 |
| 列表行 | 图标 + 名称 + 发布者 + 大小 + **安全徽章**；「卸载」主按钮；「…」进详情 |
| 残留分组 | 推荐清理 / 谨慎 / 保护（默认只选「推荐」） |
| 确认 | **不弹 3 层对话框**；页内底部条：`将清理 28 项 · 预计释放 120 MB · [确认清理]` |
| 完成 | 大数字结果 + 「14 天内可恢复」 |

### 5.2 流程 B：一键体检（类似 Software Health）

点「立即体检」→ 后台扫描 → 页内卡片：

| 卡片 | 示例 | 操作 |
|------|------|------|
| 可安全清理残留 | 86 项 / 1.2 GB | 一键清理 |
| 疑似流氓/捆绑 | 3 个 | 查看 |
| 久未使用软件 | 5 个 | 卸载 |
| Agent 缓存 | 2.4 GB | 深度清理 |

> 小白只看「一键清理」；点卡片展开明细。

### 5.3 流程 C：深度清理（向导式）

```
选择类型：残留碎片 | 历史孤儿 | Agent 工具 | 浏览器扩展
→ 扫描 → 勾选 → 清理 → 报告
```

Agent 使用 L1–L5 分层，**默认只推荐 L1/L2**，L4/L5 单独「谨慎操作」折叠。

### 5.4 流程 D：强制卸载（进阶）

工具箱 → 拖入文件/文件夹/快捷方式 → 痕迹列表（多选）→ 清理  
**不进主按钮区**，避免误用。

                    [返回]  [确认清理]

## 8. 交互规范（落地约束）

| 场景 | 规范 |
|------|------|
| 危险操作 | 不默认勾选；用「推荐/谨慎/保护」三档 |
| 二次确认 | 仅高风险/不可恢复；一般清理用底部确认条 |
| 弹窗 | 系统组件/凭证删除才用模态 |
| 进度 | >1s 显示进度；可取消 |
| 空状态 | 「很干净，没有需要清理的残留」 |
| 错误 | 说人话 + 可重试 |
| 反馈 | 清理后 Toast + 报告入口 |

## 9. 文案与信任体系

| 位置 | 文案示例 |
|------|----------|
| 主 CTA | 「立即体检」而非「深度清理」 |
| 清理按钮 | 「清理到安全区（可恢复）」 |

## 11. 成功指标

| 指标 | 目标 |
|------|------|
| 首次完成卸载+清理 | ≤ 3 次点击进入清理确认 |
| 主界面按钮数 | ≤ 3 个主操作 |
| 新用户「不敢点」 | 完成页可恢复 + 推荐默认勾选 |
| 重复入口 | 0（残留/孤儿/强制不再并列） |
| 设置项主界面 | 0（语言/主题全进设置） |

---

## 12. 结论与下一步

**结论**：简卸功能能力已接近市面中端卸载工具，但**主因是「界面信息架构 + 信任设计」**，不是缺功能。应优先：

1. **做减法**（IA、按钮、设置收纳）  
2. **一条主清理流水线**  
3. **一键体检 + 可恢复承诺**  

**待您确认后开发顺序建议**：S1 做减法 → S2 主路径 → S3 体检 → S4 工具箱。

# 测试策略

## 分层

| 层级 | 工具 | 时机 | 目标 |
|------|------|------|------|
| 单元 | xUnit + FluentAssertions | 每 PR | Core/Safety/AgentRules |
| 集成 | xUnit + 临时目录/注册表测试键 | 每日/PR | Inventory/Leftover/Uninstall |
| UI 冒烟 | 手动 + 后续 UI 自动化 | 每日构建 | 启动、列表、审阅、取消 |
| 安全 | 专用套件 `Safety.*` | 触碰删除必测 + 发版 | 误删防护 |
| 兼容 | 手工矩阵 | 发版前 | OS/缩放/主题/权限 |
| 性能 | 基准脚本 | 里程碑 | 列表与扫描预算 |

## 覆盖率

- `CleanSlate.Core` / `CleanSlate.Safety` / `CleanSlate.AgentRules`：行覆盖 ≥ 60%（逐步提高）  
- 删除白名单与风险分级：100% 关键路径覆盖  

## 安全用例（必须）

1. 保护路径无法被勾选/删除  
2. 高风险项默认不选中  
3. 全选含高风险时二次确认  
4. 隔离区可完整恢复  
5. 撤销日志完整  
6. 标准用户与管理员行为符合预期  
7. Agent L4 凭证、L5 模型默认不选  

## 样本软件矩阵（待补全）

| 软件 | 类型 | 关注点 |
|------|------|--------|
| 7-Zip | NSIS/Inno | 常规残留 |
| Notepad++ | NSIS | 配置残留 |

## 缺陷级别

| 级别 | 例 | 响应 |
|------|----|------|
| P0 | 可能误删用户文档 | 立即停发 + 修复 |
| P1 | 卸载失败/崩溃 | 24–48h |
| P2 | UI/文案 | 迭代内 |

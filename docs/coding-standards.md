# 编码规范

## C# 约定

- 文件范围命名空间：`namespace X;`
- 异步：`async` 方法以 `Async` 结尾；避免 `async void`（事件除外）
- 命名：PascalCase 方法/类型；`_camelCase` 私有字段
- 集合：优先 `IReadOnlyList<T>` 作为对外参数
- 异常：不吞异常；边界处捕获并记日志；错误码见 `docs/api/error-codes.md`
- 日志：结构化；不记录凭证、完整用户文档路径以外的隐私内容（路径可记）

## 安全编码（删除类产品）

1. **路径规范化**后再比较；拒绝 `..` 穿越出允许根。  
2. **TOCTOU**：检查与删除尽可能紧凑；删除前二次确认存在性与安全描述符。  
3. **白名单优先**：命中保护路径直接拒绝，不进入用户勾选。  
4. **最小权限**：主进程不常驻管理员；提权仅辅助进程。  
5. **规则包**：只加载带校验的本地/签名规则；禁止任意脚本执行。  
6. **默认不删用户内容**（文档、桌面、下载、源码仓库、模型）。  

## 代码审查清单（PR）

- [ ] 是否触碰删除/注册表/服务？若是，SEC 审批  
- [ ] 保护路径与红项默认策略是否正确  
- [ ] 是否可恢复（隔离区/回收站）  
- [ ] 日志与错误码是否完整  
- [ ] 单元测试是否覆盖边界  
- [ ] UI Token/可访问性（若 UI）
